## 🚀 Deployment & GitHub Hosting

### Free Hosting on GitHub Pages:
1. Push this repository to GitHub under the branch `hiren-portfolio` (or `main`).
2. Navigate to **Repository Settings** > **Pages**.
3. Under **Source**, select **Deploy from a branch**.
4. Choose the branch `hiren-portfolio` and folder `/ (root)`, then click **Save**.
5. Your live website will be accessible at: `https://<your-username>.github.io/<repository-name>/`
